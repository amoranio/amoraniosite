Notes

About this page

The game

Three levels, four enemy types, three weapons and a boss. Every link block you break releases an emblem; collecting it unlocks that link both in the game and in the list above.

How it is built

Hand-written HTML, CSS and canvas — no framework, no build step, no trackers. The pixel art is authored as character grids and baked into sprites at load.

Pop-ups

Links now open from a key press or a click rather than automatically, so pop-up blockers stay out of the way. Nothing opens without you asking.
